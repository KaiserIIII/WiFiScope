# Changelog

## 0.2.0 — 2026-11-22

- Added the network workbench with an interactive evidence map, packet timeline, device configuration comparison and layered diagnostics.
- Added typed relationships from PCAP, Cisco IOS records, local snapshots and imported scanner reports. Safety findings retain frame, sample or configuration line references.
- Added offline Zeek conn.log import with directional flow visualization, VLAN-aware nodes, source line references and coverage indicators.
- Added a self-contained Windows x64 portable build with pinned CPython and Tcl/Tk, with version reporting in the CLI and desktop title.

## 0.1.0 — 2026-10-28

- Added read-only Windows/Linux local evidence adapters, Wi-Fi checks and explicit bounded DNS/TCP/TLS/HTTP diagnostics.
- Added Nmap/Greenbone imports, offline PCAP/PCAPNG metadata analysis and typed multi-source investigation/coverage.
- Added privacy-default JSON/CSV/static HTML bundles, conservative snapshot comparison and local immutable SQLite case history with workflow triage and verification receipts.
- Added Chinese Tk workstation, CLI, source launchers, bilingual instructions and pinned read-only CI configuration.
- Included only synthetic/loopback tests. Native platform and display validation limits are recorded in `docs/validation.md`; configuring CI does not establish hosted execution evidence.
